# Lunch Order System - Project Summary

## 1. Project Overview
The **Lunch Order System** is a full-stack enterprise-grade application designed to streamline the process of managing and placing food orders for teams. It leverages modern development paradigms to provide a robust backend and a premium, responsive frontend experience.

## 2. Technology Stack

### Backend (SAP CAP)
- **Core**: SAP Cloud Application Programming Model (Node.js)
- **Database**: SQLite (Development) / SAP HANA (Production)
- **OData**: V4 protocol
- **Deployment**: SAP BTP (Business Technology Platform) via MTA

### Frontend (React)
- **Framework**: Vite + React 19
- **Styling**: Tailwind CSS (with Neobrutalism and Premium aesthetic principles)
- **Animations**: Framer Motion
- **Data Fetching**: TanStack Query (React Query)
- **Internationalization**: i18next + react-i18next (Supporting English and Vietnamese)
- **Routing**: React Router 7
